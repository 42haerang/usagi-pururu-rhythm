# 채보 수정 v5

사용자가 표시한 후반 구간의 개별 타이밍을 검토했습니다. 전체 싱크 보정값은 변경하지 않았습니다.

## 수정

- 반복 인어 코러스 4개: 24.14, 24.57, 24.86, 25.14초. 두 번째부터 네 번째가 약 0.18초 빠르던 간격을 수정.
- 25~29초대 주선율과 응답 5개를 각 발성 시작점으로 미세 조정.
- 마지막 8음절의 파형 대응을 수정. 마지막 하는 44.08초에서 43.24초로 이동. v4에서 뒤쪽 피크에 잘못 대응시켰던 배치를 정정.
- 누락 인어 하와 전체 86개 음절 순서는 유지.

## 근거와 한계

앞 코러스 구간 전체의 발성 에너지 윤곽을 원본 뒤 구간과 비교했습니다. 중앙 성분 상관 0.868, 스테레오 차이 성분 상관 0.893, 구간 차이 약 13.74초였습니다. 이는 같은 응답의 간격을 비교하는 근거이며 발음을 자동 판독한 결과는 아닙니다. 음절 순서는 사용자 제공 내용에 근거합니다. 전곡 직접 청취 검증이나 사용자의 기기에서 실제 플레이 검증을 마친 상태는 아닙니다.
