# v6: 마지막 음절과 연습 비트 분리

- 랩의 마지막 8음절만 41.02, 41.57, 41.84, 42.15, 42.43, 42.70, 42.98, 43.28초로 조정. 발성 신호 기반 추정이며 직접 청취 검증을 마친 시점은 아닙니다.
- 마지막 구간 이전의 랩 이벤트는 v5와 객체 단위로 동일함을 비교했습니다.
- 연습 비트는 랩 채보와 분리. 105 BPM, 첫 박 2초, 한 박에 한 노트, 7개 버튼을 순서대로 10회 순환합니다.
- 비트는 25ms 간격으로 다음 120ms를 살펴 Web Audio 시각에 미리 예약합니다. 노트와 같은 이벤트 시간을 사용합니다.
- 연습에서는 랩의 외침 보너스가 발동하지 않으며 마지막 박까지 비트가 이어집니다.
- 일시정지·재시작 시 예약된 비트를 중지하고 현재 시각부터 다시 예약합니다.
