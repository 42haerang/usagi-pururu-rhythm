# 마지막 8음절 입력 보정

마지막 음절의 기본 시점을 다시 추정해 옮기는 대신, 원곡에서 사용자가 누른 8개 시점을 마지막 블록에만 적용하도록 추가했습니다.

1. 우사기 랩을 선택하고 '마지막 8음절 직접 맞추기'를 엽니다.
2. '마지막 부분 듣고 기록하기'를 누릅니다. 원곡의 40.5초부터 재생합니다.
3. 마지막 하·야·하·이·이·이·야·하 소리에 맞춰 큰 버튼을 8번 누릅니다. 스페이스도 사용할 수 있습니다.
4. '이 타이밍으로 적용'을 누르면 이 브라우저에 저장되고 다음 플레이부터 적용됩니다.

기본 랩 채보와 연습 채보는 변경하지 않았습니다. 기록을 적용할 때도 앞의 78개 이벤트 및 연습의 70개 이벤트는 보존됩니다. 보정값은 외부로 전송하지 않고 로컬 저장소 pururu.outro.v1에 저장합니다. 되돌리기는 이 기록만 지웁니다.

기본 마지막 시점을 청취 검증하여 확정한 것은 아닙니다. 8회 입력이 필요한 기능이며 사용자가 입력을 마치기 전에는 기존 기본 시점으로 플레이합니다. YouTube 원곡이 재생 가능한 환경이 필요합니다.
